# Контент сайта

Папка `content/ru` содержит переработанный хэндбук ШЭМ в формате Markdown. Это черновой контентный слой для будущего сайта.

## Почему Markdown

Markdown удобен для проекта, потому что:

- его можно читать без запуска сайта;
- его легко хранить в Git;
- его можно подключить в React/Vite через MDX или markdown-парсер;
- позже его можно редактировать через Decap CMS, TinaCMS или другую CMS;
- текст отделен от UI-кода.

## Структура

- `index.md` - главная навигация по материалам.
- `start.md` - первые сервисы: личный кабинет, почта, зачетка.
- `study.md` - ежедневная учеба: расписание, учебный план, рейтинг, библиотека.
- `exams.md` - сессия, оценки, пересдачи.
- `rules-support.md` - правила, поддержка, академическая честность.
- `student-status.md` - индивидуальный график, академический отпуск, отчисление.
- `opportunities.md` - стипендии, конкурсы, волонтерство, наука, мобильность, карьера.
- `portfolio-feedback.md` - портфолио, характеристика, обратная связь.
- `about-sem.md` - краткая информация о ШЭМ и структуре.
- `contacts.md` - контакты и маршрутизация вопросов.

## Метаданные

В начале каждого файла есть frontmatter:

```yaml
---
id: start
category: start
title: Начать учиться
summary: Первые цифровые сервисы, которые нужны студенту ШЭМ.
source: "Раздел 3 и Приложение хэндбука ШЭМ"
lastReviewed: 2026-05-01
related:
  - contacts
---
```

Эти поля можно использовать для генерации меню, карточек, SEO, связанных статей и статуса актуальности.

## Что важно проверить перед публикацией

Контент переработан из хэндбука простым языком, но перед публикацией нужно проверить:

- актуальность контактов;
- актуальность кабинетов и телефонов;
- правильность email-адресов;
- актуальность ссылок на разделы сайта ДВФУ;
- юридически чувствительные формулировки про отчисление, отпуска, визы и регистрацию;
- переводы на английский и китайский.
