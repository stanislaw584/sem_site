# 考试与成绩

考试周是各门课程进行总结评定的时期。在经管学院，最终成绩通常取决于学生在整个学期累积的综合评分。

## 主要的期中考核

期中考核形式包括：

- 考查；
- 有分数的考查；
- 考试。

考核形式通常会在培养计划和该门课的评分计划中注明。

## 综合评分如何转化为成绩

| 学生评分 | 考查 | 考试 |
| --- | --- | --- |
| 低于 61% | 不通过 | 不及格 |
| 61-75% | 通过 | 及格 |
| 76-85% | 通过 | 良好 |
| 86-100% | 通过 | 优秀 |

## 考查周

考查周是学期理论教学的最后一周。在这期间通常会完成以下考核形式的课程：

- 考查；
- 有分数的考查；
- 课程设计；
- 评分计划中考试权重为零的课程。

考查周也可能进行分散实习的考核。

## 考试周

考试周在理论教学结束后进行。它针对评分计划中考试权重不为零的课程。

如有考试，会在课表中安排单独一天，学生在这一天获得该门课的最终成绩。

## 如何了解考试时间

请查看：

- 校历学习日程；
- 远东联邦大学网站上的课程表；
- 校园邮箱；
- 教师的通知；
- 教育项目副负责人的信息。

校历日程中可能使用一些符号，例如：

- `Э` —— 考试周；
- 学习、实习和假期其他时期的符号。

## 考试结束后必须做的事

1. 打开个人账户。
2. 检查**评分**栏目。
3. 检查**成绩册**栏目。
4. 确认所有最终成绩显示正确。

重要提示：成绩不仅应出现在"评分"中，也应出现在"成绩册"中。

## 如果成绩有误

1. 首先联系教师。
2. 如果问题无法解决，通过个人账户提交申请：
   **申请 / 一站式服务窗口 / 向学校提交正式申请 / 学习 / 教学过程 / 成绩册 / 成绩修改申请**。
3. 不要拖延：错误最好在考试结束后立刻更正。

## 个人考试时间安排

如果学生因正当理由无法在规定时间内完成考核，可申请个人考试时间安排。

需要通过"一站式服务窗口"联系学生事务办公室办理。请提前准备好证明原因的相关文件。

## 补考与学业欠科

如果学生未通过某门课程的考核，则会产生学业欠科。

补考按已批准的时间表进行。时间表发布在远东联邦大学网站的**学习 / 学业欠科补考**栏目。

学生本人需负责：

- 查看补考时间表；
- 做好准备；
- 按时到场；
- 提前向教师或教育项目副负责人确认不明之处。

## 学科补考委员会

如果在常规补考中未能消除欠科，可能会成立学科补考委员会。具体情况取决于实际情况和学校规定。

如果不清楚自己处于补考的哪个阶段，请联系教育项目副负责人或学生事务办公室。

## 争议调解委员会

如果学生对考核或成绩有异议，可以向争议调解委员会提交申请。

申请通过个人账户**一站式服务窗口**栏目提交。申请中需说明争议的具体情况，并附上相关材料。

委员会将在收到申请后30个日历日内做出决定。

## 经管学院的主要建议

- 每个学期结束后检查成绩。
- 不要忽略学校的来信。
- 一旦出现欠科，立即了解补考流程。
- 不要等到最后一天才提交申请。
- 如果不理解补考时间表，请寻求咨询。
- 遵守学校纪律和规定：违规可能导致处分。
