# 联系方式

如果不知道该向谁求助，请先联系经管学院行政办公室或学生事务办公室。他们会将您的问题转交给合适的部门。

## 快速指引

| 问题 | 联系对象 |
| --- | --- |
| 学习、课程表、班级、学习相关冲突 | 经管学院行政办公室或教育项目副负责人 |
| 申请、证明、个人学习计划、学术休假、退学 | 学生事务办公室 / 一站式服务窗口 |
| 签证、登记、国际学生 | 国际学生事务办公室、签证与登记办公室 |
| 宿舍与住宿 | 住宿与接待办公室 / 宿舍管理 |
| 个人账户、邮箱、Wi-Fi、统一账户 | 技术支持 |
| 奖学金 | 奖学金项目部 |
| 课外活动 | 经管学院学生中心 |
| 比赛、学术流动、差旅资助 | 发展项目与全院服务办公室 |
| 心理援助 | 应急中心、综合诊所、心理援助热线 |
| 安全、通行证 | 综合安全部 |

## 远东联邦大学：学生事务办公室

学生事务办公室采用"一站式服务"模式。通过该办公室可以：

- 提交学术休假或退学申请；
- 提交课程学分认定申请；
- 办理个人考试时间安排；
- 办理个人学习计划或时间表；
- 提交转学申请；
- 修改个人信息；
- 获取在读证明；
- 咨询学习成绩相关问题。

申请可以通过**个人账户 / 申请 / 一站式服务窗口**远程提交。

联系方式：

- 地址：俄罗斯岛，远东联邦大学校园E楼6层5区E639室；
- 参照物："圆盘建筑"，从F楼方向街道入口进入；
- 电话：`8 (423) 265 24 24`，分机 `2164`、`2118`；
- 邮箱：`documents@dvfu.ru`。
