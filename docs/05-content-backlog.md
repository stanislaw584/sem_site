## Метаданные для каждой статьи

У каждой статьи должны быть:

- `id`;
- `title`;
- `summary`;
- `category`;
- `language`;
- `priority`;
- `source`;
- `contacts`;
- `lastReviewed`;
- `related`.

## Контакты, которые нужно собрать отдельно

Нужна отдельная база контактов для:

- Административного отдела ШЭМ;
- Студенческого центра ШЭМ;
- Студенческого офиса / "Единого окна";
- отдела по работе с иностранными студентами;
- отдела виз и регистраций;
- службы общежитий или проживания;
- технической поддержки;
- психологической поддержки;
- безопасности и экстренных ситуаций.

Для каждого контакта нужны:

- название;
- с какими вопросами помогает;
- email;
- телефон;
- кабинет или адрес;
- часы работы;
- источник и дата проверки.
